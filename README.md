# Shashi Kant - React Portfolio

A modern, responsive, and beautifully animated portfolio website built with React.js, showcasing professional experience, skills, projects, and services.

## ✨ Features

- **Modern Design**: Beautiful glassmorphism effects and gradient backgrounds
- **Fully Responsive**: Optimized for all devices and screen sizes
- **Smooth Animations**: Powered by Framer Motion for engaging user experience
- **Interactive Elements**: Hover effects, gestures, and scroll-triggered animations
- **Performance Optimized**: Fast loading and smooth scrolling
- **SEO Friendly**: Proper meta tags and semantic HTML structure

## 🛠️ Built With

- **React.js 18** - Frontend framework
- **Framer Motion** - Animation library
- **React Router** - Navigation
- **React Icons** - Icon library
- **CSS3** - Modern styling with custom properties
- **Intersection Observer API** - Scroll-triggered animations

## 🚀 Key Sections

1. **Hero Section** - Animated introduction with typing effect
2. **About** - Personal information with interactive stats
3. **Certificates** - Professional certifications with modern cards
4. **Skills** - Interactive skill bars with categories
5. **Resume** - Timeline-based experience and education
6. **Projects** - Filterable project showcase
7. **Services** - Offered services with detailed descriptions
8. **Contact** - Interactive contact form with validation

## 📱 Responsive Design

- **Desktop**: Full sidebar navigation with desktop-optimized layouts

- **Mobile**: Collapsible navigation with mobile-first approach

## 🏃‍♂️ Getting Started

### Prerequisites

- Node.js (version 16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/your-username/shashi-portfolio-react.git
cd shashi-portfolio-react
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
```
