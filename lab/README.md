# Digital Laboratory Portfolio

Premium React + TypeScript + React Three Fiber portfolio for **Shashi Kant**.

## Stack

- Vite · React 19 · TypeScript
- Three.js · React Three Fiber · Drei · Postprocessing
- GSAP ScrollTrigger
- Blender-sculpted computational core (`public/models/computational-core.glb`)

## Develop

```bash
cd lab
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Art direction

Theme: **Digital Laboratory / Computational Architecture**

- One primary 3D identity object (not planets/spaceships)
- Scroll evolves STATE 01→05 (intro → engineering → projects → about → contact)
- Restrained OLED palette + single soft-cyan accent
- Reduced-motion & mobile simplify camera / postprocessing
